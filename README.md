This is an application written in Rust for a school project. It's an implementation of the RSA public key algorithm entirely hand coded. This was my first journey into Rust, even though the requirement for this project was to use python! I must be a masochist.

Features:
- Command line argument parsing
- Key generation from secrets
- Block encryption (If you exceed the limit of characters that can be encrypted, a block is tacked on)
- Read from file or stdin
- Output to file or stdout
